Authenticator 앱 설치 가이드

관리자 로그인 시 2단계 인증(2FA) 에 필요한 인증 앱을 휴대폰에 설치하는 방법입니다.

2FA 가 뭐예요?

아이디·비밀번호 외에 휴대폰 앱이 30초마다 새로 만들어 주는 6자리 숫자를 한 번 더 입력하는 것입니다. 비밀번호가 유출되어도 휴대폰이 없으면 로그인이 안 되므로 관리자 계정 보안이 크게 강화됩니다.

1단계 — 앱 선택

아래 3가지 앱 중 아무거나 하나만 설치하시면 됩니다. 처음이라면 가장 보편적인 Google Authenticator 를 권장합니다.

Google Authenticator

가장 많이 쓰이는 표준 앱

  • Google 계정으로 백업
  • 새 휴대폰에 옮기기 쉬움
  • 한국어 지원

Microsoft Authenticator

Microsoft 계정 사용자 추천

  • 알림(Push) 인증 지원
  • 회사 Office 365 와 통합
  • iCloud/Microsoft 백업

Authy

여러 기기 동기화 필요 시

  • 휴대폰 + 태블릿 + PC 동시
  • 전화번호 기반 백업
  • 영문 인터페이스

2단계 — 휴대폰에 앱 설치

📱 Android (갤럭시·LG 등)

  1. 홈 화면에서 Play 스토어 (▶ 모양 아이콘) 열기
  2. 상단 검색창에 Google Authenticator 입력
  3. "Google LLC" 가 만든 앱 옆 설치 버튼 탭
  4. 설치가 끝나면 열기 또는 홈 화면 아이콘 탭

🍎 iPhone (아이폰)

  1. 홈 화면에서 App Store (파란 A 아이콘) 열기
  2. 하단 검색 탭 → Google Authenticator 입력
  3. "Google LLC" 가 만든 앱 옆 받기 버튼 → Face ID/암호 인증
  4. 설치가 끝나면 열기 또는 홈 화면 아이콘 탭

※ Microsoft Authenticator / Authy 도 같은 방식으로 검색해 설치할 수 있습니다.

3단계 — GoPCMS 계정 추가

앱이 설치되었으면, 2FA 설정 페이지 를 열고 다음과 같이 진행합니다.

  1. 휴대폰의 Authenticator 앱을 열고 화면 오른쪽 아래 + 또는 "계정 추가" 버튼을 탭
  2. "QR 코드 스캔" 선택 (Microsoft Authenticator 는 "QR 코드", Authy 는 "Scan QR Code")
  3. 카메라 권한을 허용하고 — PC 화면의 QR 코드를 휴대폰 카메라로 비춤
  4. 앱 화면에 "GoPCMS:<아이디>" 항목이 추가되며 6자리 숫자가 표시됨 (30초마다 자동으로 바뀜)
  5. PC 화면 "코드 검증" 입력란에 그 6자리를 입력 → 활성화 버튼 클릭

자주 묻는 질문

QR 코드를 스캔할 수 없어요. 어떻게 하나요?

2FA 설정 페이지의 "QR 스캔이 어렵다면? (수동 입력)" 영역을 펼쳐 표시되는 base32 secret 문자열을 복사하세요. 앱에서 "+ → 설정 키 입력" 메뉴를 선택하고 계정명에 임의 이름(예: GoPCMS), 키 입력란에 그 문자열을 붙여넣고 "시간 기반(Time-based)" 을 선택해 추가하면 됩니다.

코드를 입력했는데 "코드가 일치하지 않습니다" 가 나와요.

대부분 휴대폰 시간 오차 때문입니다. 다음을 확인하세요:

  • 휴대폰 설정 → 일반 → 날짜·시간 → "자동 설정" 활성화
  • Google Authenticator 의 경우: 우측 상단 ⋯ → 설정 → "코드 시간 동기화"
  • 코드는 30초마다 바뀌므로, 새 코드가 나오면 즉시 입력하세요(끝나기 직전 입력 시 만료될 수 있음)
휴대폰을 잃어버리거나 바꾸면 어떻게 하나요?

GoPCMS 시스템 관리자에게 연락하여 본인 확인 후 2FA 를 초기화 받으세요. 초기화 후 새 휴대폰에서 이 페이지의 절차를 다시 진행하면 됩니다. 2FA secret 은 사진 촬영해 보관하지 마세요 — 유출 시 보안 의미가 사라집니다.

여러 사이트의 2FA 를 같은 앱에 등록해도 되나요?

네, 권장됩니다. 한 앱에 회사 Google 계정, GoPCMS, 은행 등 여러 서비스의 2FA 를 같이 등록할 수 있고 각각 별도의 6자리 코드가 생성됩니다.
