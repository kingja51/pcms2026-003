기능 설명

  • 드래그앤드롭 또는 파일 선택 다이얼로그로 여러 파일 업로드
  • 업로드는 백그라운드에서 /api/v1/file/upload 로 비동기 전송
  • 업로드 완료된 파일의 fileId 를 hidden input(JSON 배열)에 누적
  • 개별 파일 삭제 버튼 — UI 에서 제거 + hidden input 갱신
  • 이미지는 썸네일 자동 표시 (서버가 비동기 생성 완료 시)
  • 업로드 진행률·성공·실패 상태 실시간 표시
  • 읽기 전용 모드 — 상세 보기에서 드롭존 숨김·삭제 버튼 비활성
  • CSRF 자동 처리 (<meta name="_csrf"> 읽기)

다른 화면에서 재사용하기

게시판/콘텐츠 등 다른 Thymeleaf 페이지의 등록·수정·상세 폼에서 아래처럼 include: 

<!-- <head> -->
<th:block th:replace="~{fragments/file-picker :: styles}"/>

<!-- <body> 폼 내부 -->
<form th:action="@{/board/save}" method="post">
  ...
  <div th:replace="~{fragments/file-picker :: picker(
      inputName='attachments',
      category='ANY',
      multiple=true,
      existingFiles=${existing},
      readOnly=false,
      entityType='BBS',
      entityId=${board.boardId},
      siteId=${site.siteId},
      maxFiles=20,
      fileGroupId=${board.fileGroupId}
  )}"></div>
  ...
</form>

<!-- </body> 직전 -->
<th:block th:replace="~{fragments/file-picker :: scripts}"/>

서버 Controller 는:

@PostMapping("/board/save")
public String save(@RequestParam("attachments") String attachmentsJson, ...) {
    // attachmentsJson = ["019d...","019d..."]
    List<String> fileIds = new ObjectMapper().readValue(
        attachmentsJson, new TypeReference<List<String>>(){});
    // 자체 테이블 (예: tb_bbs_attach) 에 게시글 ID + fileId 매핑 저장
    ...
}

파라미터

이름 타입 기본값 설명
inputName String fileIds hidden input 의 name (폼 제출 키)
category String ANY DOC / IMAGE / VIDEO / ANY
multiple boolean true 여러 파일 허용 여부
existingFiles List<FileItem> [] 수정/상세 시 기존 파일 시드
readOnly boolean false true 면 드롭존 숨김·삭제 버튼 숨김
entityType String ETC BBS/CNT/MBR/POPUP/MAIL/ETC
entityId String (빈값) 상위 엔티티 ID — 같은 그룹에 묶기
siteId String (빈값) 멀티사이트 구분
maxFiles int 20 최대 업로드 개수

커스텀 이벤트

파일 추가/삭제 시 fp:change 이벤트 발행. detail.fileIds 로 현재 목록 접근:

document.addEventListener('fp:change', (e) => {
  console.log(e.detail.fileIds);   // ["019d...", ...]
});
