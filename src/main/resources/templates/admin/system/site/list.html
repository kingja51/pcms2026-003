테마 가이드

테마란

테마는 사이트 <html> 태그에 부착되는 theme-* 클래스입니다. 레이아웃·구조는 그대로 두고 템플릿 CSS의 브랜드 색상 팔레트(--brand-* 11단계)만 교체합니다. 비워 두면 적용 템플릿의 기본 브랜드 색으로 렌더링됩니다.

적용 방법

  1. 사이트 수정 화면의 테마 입력란에 테마명 입력 — 예: theme-navy (접두사 생략 navy 도 허용, 저장 시 자동 보정)
  2. 저장하면 재기동 없이 즉시 반영됩니다 (사이트 컨텍스트 캐시 자동 무효화) — 사용자 화면을 새로고침해 확인하세요
  3. 해제하려면 입력란을 비우고 저장 — 템플릿 기본 브랜드로 복귀

테마 적용은 이 화면(DB 저장)이 유일한 경로입니다 — 별도 URL 파라미터 프리뷰는 없습니다.

아래 표에 없는 테마명을 지정하면 오류 없이 기본 브랜드로 표시됩니다 (해당 CSS 규칙이 없기 때문).

템플릿별 사용 가능 테마

유효 테마는 사이트의 기본 템플릿이 무엇이냐에 따라 다릅니다. 각 템플릿 CSS가 자신의 대체 테마 3종을 정의하며, 테마를 비우면 아래 "기본 브랜드" 색으로 렌더링됩니다. 템플릿 이름은 수정 화면의 템플릿 선택 목록과 동일합니다.
