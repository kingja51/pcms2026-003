⚙️ 처리 규칙

  • 인코딩: UTF-8 (BOM 허용) 또는 CP949(MS949) / EUC-KR — 첫 줄 sniffing 으로 자동 감지
  • 구분자는 확장자로 자동 결정: .csv → 쉼표(,) / .dat → 파이프(|)
  • MyBatis BATCH 1000건 단위 chunk commit — 10만 건 ≈ 5~15초
  • 1행 실패는 다른 행 처리를 막지 않음 (부분 적재). 실패 사유는 화면 + 서버 로그에 기록
  • 모든 PII (성명/생년월일/주민번호 끝3자리)는 AES-256-GCM 암호화 저장 + 검색용 HMAC-SHA256 hash 동시 생성
