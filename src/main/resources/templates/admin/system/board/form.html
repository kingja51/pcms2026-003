기능 옵션
파일 첨부 제약

서버 전역 한도(gopcms.file.upload.max-file-size-mb)를 초과해도 그 한도까지만 적용됩니다.

권한

로그인 사용자만 작성할 수 있습니다.

· 게시판 읽기 권한과 별개로 첨부파일 다운로드만 별도 통제합니다. 기본값 ROLE_MEMBER.
· OWNER_PRIVACY — 작성자 본인(created_by)과 ROLE_PRIVACY 보유자만 다운로드 가능. ROLE_ADMIN 도 자동 통과 안 됨. 개인정보가 첨부되는 게시판(QNA 등)에 권장.
· 게시판 마스터 변경 시 해당 게시판의 모든 기존 첨부에 일괄 cascade 적용됩니다.

통합 게시판 (전체글 보기)

· 대상 게시판들의 글을 한 화면에 모아서 보여주는 read-only 뷰로 동작합니다.
· 통합 모드에서는 작성·수정·삭제가 비활성화됩니다 (대상 게시판에서 직접 관리).
· 자기 자신을 포함 필수 (포함은 정책상 허용).
· 다른 통합 게시판은 대상으로 지정할 수 없습니다 (중첩 금지). 최대 24개.

통합 대상으로 지정할 수 있는 일반 게시판이 없습니다. 일반 게시판을 먼저 등록한 후 다시 시도하세요.
