Trace 추적

한 HTTP 요청의 trace_id 로 4개 log_* 테이블 (access · audit · error · file-download) 을 시간순 통합 조회합니다.

📁 더 자세한 추적이 필요한가요?

본 timeline 은 4개 log_* 테이블의 구조화된 이벤트만 표시합니다. DEBUG/INFO/WARN 등 모든 logger 출력은 서버의 *.log 파일에 있습니다.

운영에서는 운영팀에게 다음 명령으로 grep 을 요청하세요: grep 'TRACE_ID' /var/log/gopcms/*.log — 또는 Loki/Elasticsearch 같은 로그 수집기에서 traceId="TRACE_ID" 검색.

위 입력란에 trace_id 를 넣어주세요. 각 로그 상세 화면의 "trace_id" 항목에서 복사할 수 있습니다.

trace

일치하는 로그가 없습니다. trace_id 가 정확한지, 또는 6개월 retention 으로 삭제되었는지 확인하세요.
